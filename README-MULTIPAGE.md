# SlimeCube Multi-page Portfolio

## Páginas
- `index.html` — página principal
- `box-pvp/index.html` — página BoxPvP
- `lobbys/index.html` — página Lobbys
- `fullpvp/index.html` — página FullPvP

## Enlaces desde la página principal
Las tarjetas de Builds enlazan automáticamente a `box-pvp/index.html`, `lobbys/index.html` y `fullpvp/index.html`. Los enlaces explícitos también funcionan al abrir el portfolio como archivos locales.

## Imágenes
Coloca tus capturas en `assets/images/`:
- `boxpvp.jpg`, `boxpvp-01.jpg` ... `boxpvp-06.jpg`
- `lobby.jpg`, `lobby-01.jpg` ... `lobby-06.jpg`
- `fullpvp.jpg`, `fullpvp-01.jpg` ... `fullpvp-06.jpg`

Si no añades una imagen, se mostrará una imagen de reemplazo. Usa tus propias capturas para publicar el portfolio.

## GitHub Pages
Sube todos los archivos y carpetas al repositorio. En Settings → Pages selecciona Deploy from a branch → `main` → `/ (root)`.
Las rutas serán `https://TU-USUARIO.github.io/NOMBRE-REPO/box-pvp/`, `/lobbys/` y `/fullpvp/`.
